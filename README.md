# 🎲 Number Draw – Rocketseat

Este projeto foi desenvolvido como tarefa de conclusão do módulo *Javascript Intermediário* do curso da [Rocketseat](https://www.rocketseat.com.br/).
Trata-se de um sorteador de números que recebe a quantidade de números a serem sorteados e os valores de início e fim.
Os números sorteados podem se repetir ou não, de acordo com a opção selecionada pelo usuário.

## 🛠️ Tecnologias

- **HTML5** → estrutura da página  
- **CSS3** → estilização e layout  
- **JavaScript (DOM)** → lógica principal, manipulação de eventos e criação dinâmica de elementos

## 📚 Aprendizados

- Manipulação do DOM (captura de elementos, eventos e estilos)
- Aplicação e remoção de classes dinamicamente com JavaScript
- Estruturação semântica com HTML5
- Organização dos estilos com boas práticas de CSS
